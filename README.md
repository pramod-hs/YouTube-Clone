# 🎬 YouTube Clone — Dark Mode

A responsive **YouTube Clone UI** built using **HTML and CSS**. This project recreates the look and feel of YouTube with a modern **dark-mode-only interface**.

## ✨ Features

* 🌙 Dark mode only
* 🎥 YouTube-inspired video grid
* 🔍 Search bar UI
* 📺 Video thumbnails
* 👤 Channel/profile section
* 📱 Responsive layout
* 🎨 Modern dark UI
* 🧭 Sidebar navigation
* ▶️ YouTube-style buttons and cards
* ⚡ Built with pure HTML & CSS

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

> No JavaScript is used in this project.

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/youtube-clone.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

## 🌙 Design

The project uses a **dark-mode-only theme** inspired by YouTube's dark interface.

* ⚫ Dark background
